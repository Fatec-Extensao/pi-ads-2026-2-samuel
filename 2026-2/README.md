## 📌 Visão Geral do Projeto

* **Etapa:** Etapa 2 – Fase de Prototipação: Estruturação de Interface Web e Modelagem de Dados
* **Temática:** Desenvolvimento de interfaces web (Front-End estático) e projeto de banco de dados para demandas reais.
* **Título:** Sistema Web para Gestão de Pesquisas por Questionários
* **Atuação:** `[ X ] Programas` `[ ] Projetos` `[ ] Cursos e oficinas` `[ ] Eventos` `[ ] Prestação de serviços`
* **Carga Horária:** 30 horas / aula semestrais
* **Público-alvo:** Qualquer Instituição que necessite de realizar uma pesquisa institucional com a aplicação de questionário.

### 📝 Descrição do Projeto
O projeto tem como objetivo proporcionar aos estudantes uma experiência prática de desenvolvimento de software, envolvendo análise de requisitos, modelagem de dados, desenvolvimento de aplicações web, usabilidade, segurança da informação e geração de relatórios analíticos.

O sistema a ser desenvolvido deverá permitir a criação, aplicação e análise de pesquisas institucionais via questionário, garantindo anonimato dos participantes e organização das respostas por categorias de respondentes.

---

## 🎯 Objetivos do Projeto

Desenvolver um Sistema Web para Gestão de Pesquisas por Questionários, permitindo:
* Cadastro e gerenciamento de pesquisas;
* Definição de categorias de participantes;
* Criação de questionários específicos por categoria;
* Aplicação da pesquisa com acesso por senha anônima;
* Coleta e armazenamento das respostas;
* Monitoramento da participação em tempo real;
* Geração de relatórios estatísticos e analíticos;
* *[Espaço reservado para novas funcionalidades propostas pela equipe]*.

### Competências Acadêmicas Desenvolvidas:
1. **Desenvolvimento Web:** Aplicar linguagens de marcação e estilo (HTML/CSS/JS básico) para construir interfaces amigáveis.
2. **Banco de Dados I:** Projetar modelos de banco de dados (Conceitual, Lógico e Físico) aderentes à regra de negócio.
3. **Engenharia de Software II:** Modelar o sistema utilizando notação UML.
4. **Compliance e Segurança da Informação:** Introduzir conceitos de conformidade (LGPD) e segurança na estrutura do projeto.

---

## 🚀 Ações e Etapas de Execução

1. Definição da identidade visual e arquitetura da informação da solução.
2. Desenvolvimento do Site Institucional ou Telas do Sistema (HTML/CSS/JS básico).
3. Modelagem do Banco de Dados (Diagramas ER e Scripts SQL).
4. Análise de conformidade básica (LGPD) e segurança no design da solução.

⚠️ ATENÇÃO - Estruturação Inicial do Repositório (2026-2)
Pessoal, o Git não envia (não faz push) de pastas vazias para o GitHub. Para garantir que toda a nossa estrutura de diretórios do semestre apareça no repositório desde o início, cada grupo deve criar um arquivo README.md dentro de cada subpasta.
Esse arquivo vai funcionar tanto para "forçar" a criação da pasta no GitHub quanto para servir de documentação sumária do que será entregue em cada disciplina.
Passo a Passo:
Na raiz do seu repositório, crie a pasta 2026-2.
Dentro de 2026-2, crie as 4 subpastas:
desenvolvimento-web/
engenharia-software/
banco-de-dados/
seguranca/
Crie um arquivo README.md dentro de cada uma dessas 4 subpastas utilizando os modelos abaixo.
